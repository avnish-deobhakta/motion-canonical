# Amendment 1 to SAP_addendum_ui_v1 (chat-interface arm)

Drafted 11 October 2026. Committed 15 October 2026, after all 480 tasks were completed and before any reply was scored or analysed. Each decision below was made on the date stated, during data collection.

Status on 11 October 2026: 60 of 480 tasks completed on 5 and 6 October 2026 (Claude 30, ChatGPT 30). No Gemini or Grok task had been run.

1. Window extended. "All tasks within 7 days of the first" is replaced by "all tasks within 28 days of the first" (by 2 November 2026). Reason: operator availability. The rule that repeat 2 of each image, prompt and app falls on a later calendar day than repeat 1 is unchanged. Tasks were completed by 15 October 2026.

2. Reasoning setting (clarification applied from the first task, 5 October): each app is used at its default reasoning or effort setting once the model is matched, and the displayed label is recorded per task.

3. ChatGPT (decided 5 to 6 October, before the first ChatGPT task): GPT-6 Astra is available in Chat mode only through the Pro option, so "Pro, Latest" was used in a Temporary, Unpersonalized chat. Work mode was not used because it cannot be run without memory and personalisation.

4. Gemini (decided 11 October, before the first Gemini task): the app shows effort levels for 3.1 Pro with Low as the default, and Low is used per item 2. Gemini memory ("Personal Intelligence") was switched off for the Gemini blocks; no saved instructions existed.

5. Grok (decided 11 October, before the first Grok task): the default mode (Fast) does not name its model; Expert is labelled Grok 4.7 in the app's picker and matches the reasoning API model, so Expert is used in a Private chat. Heavy (multi-agent) and Auto (routing) are not used. "Personalize Grok with your conversation history" was switched off for the Grok blocks.

6. On 14 October 2026 the Gemini app introduced a new default model ("Argon"). All Gemini tasks continued on 3.1 Pro at the default (Low) effort, per the same-model rule.

7. Disclosure: on 15 October the operator ran one query outside the protocol (image I25, forced prompt, Gemini "Argon"). It is not part of the dataset and is not analysed.

No other part of the protocol changes.
